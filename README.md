One of my first vibecoded ideas.
I've had the idea for imagination training with an imaginary cube for a while.
I'd imagine a cube with a red side towards me while holding a dice.
Then I'd close my eyes and turn both the dice and the cube in my imagination while keeping track of where the red side was.
This is a small game where you can do the same, try out all the six moves and select which you want to use for training.
